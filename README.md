# meddaily-digest · 医学文献日报（27 科）

面向临床医生的**每日专科文献速览 Skill**：自动抓取最新文献 → 评分选文 → 宿主 AI 逐篇生成结构化中文速览 → **数字保真校验**（速览中的每个数字必须出现在原文摘要中，不合规自动打回）→ Markdown 日报 + 本地积累库。

**零配置**：数据源全为公共学术 API（Europe PMC / PubMed / ClinicalTrials.gov），无需任何 API key；摘要由宿主 agent 的模型完成，脚本只做确定性抓取、评分与校验。

覆盖 27 个临床科室：风湿/呼吸/重症/肿瘤/心内/消化/内分泌/肾内/血液/神内/感染/麻醉/心胸外/口腔/皮肤/急诊/普外/老年/神外/妇产/眼科/骨科/耳鼻咽喉/儿科/精神/康复/泌尿。

## 它和"让 AI 搜一下总结一下"的区别

1. **数字保真校验**——速览里每一个数字（样本量/HR/OR/95%CI/P 值）都会被脚本逐篇核验必须出现在原文摘要中，不合规篇目自动打回重写。AI 不许编数据。
2. **证据分级**——每篇标注证据等级（RCT/荟萃/队列/综述…），综述绝不冒充研究；局限性单独一行。
3. **跨天去重**——本地库记录 7 天内已精读文献，同一篇绝不重复出现。
4. **专科策展**——每科 spec 含 9-10 个病种检索式、分层期刊权重（top/core/sci）、专科热点词与会议识别，评分可解释（每篇附 score 与理由）。

## 使用流程（宿主 agent 按 SKILL.md 编排）

```
1. fetch.py          抓取（3 天窗口自适应放宽、限流退避、失败不覆盖旧数据）
2. render.py plan    待摘要清单（7 天去重；滤除无摘要/无编号/空壳模板条目；默认 12 篇）
3. 宿主 AI           逐篇五行速览（标题/临床意义/要点/证据等级/谨慎解读，数字须与原文逐字符一致）
4. render.py finalize 数字保真校验 → Markdown 日报 + SQLite 积累库（未过校验篇目次日可重试）
```

## 构建

```bash
# 环境：Python 3.9+（仅标准库）；生成图标需 macOS qlmanage
python3 gen_specialty.py                # 全部 27 科 → dist/meddaily-<科>-digest-<版本>/
python3 gen_specialty.py cardiology icu # 指定科室
GEN_VERSION=1.2.0 python3 gen_specialty.py <key>   # 自定义版本（需同步在 digest/README.md 写版本记录）
```

- `digest/`：**单一通用源**——占位符模板（SKILL/README）+ 通用脚本（fetch/render/spec/db，运行时读包内 spec.json）+ 母版图标
- `specs/`：27 科配置（病种检索式/期刊权重/热点词/会议识别），是生成器的科室事实源
- 生成器自检：占位符逐文件断言 + 无残留 + 版本记录一致性 + 语法检查；验收口径 = **重生成幂等零差异**

## 目录

```
digest/            通用源（模板 + 脚本 + icon.svg）
specs/             27 科专科配置
gen_specialty.py   专科包生成器
dist/              27 科即用包（目录 + zip，可直接下载导入）
examples/          真实日报产出样例
```

## 贡献

- **加病种/调权重**：编辑 `specs/<科>.json`（期刊 key 请用 NLM 缩写）
- **加新科室**：新增 `specs/<key>.json`（参考任一现有 spec 结构）+ 在 `gen_specialty.py` 的 `SLUGS` 表加一行缩写，重跑生成器即可
- 期刊权重为人工策展的编辑分（非影响因子），top 层压过通用声望是刻意设计
